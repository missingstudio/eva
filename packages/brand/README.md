# @missingstudio/eva-brand

The brand system the websites stand on: the two faces, the palette, the
surfaces, the motion contract, and the shared marks and favicons both sites
point their `publicDir` at.

Nothing of it has landed on `main` yet. The package — `tokens.css`,
`typography.css`, `motion.css`, the fonts, and `public/` — lives on the
`feat/website` branch beside `apps/web` and `apps/docs`. This directory is its
place in the tree, and this file is all it holds until that branch lands.
