# @missingstudio/ui

The front-end system the sites and the web app stand on: the design tokens —
the two self-hosted faces, the palette, the surfaces, the motion contract —
the shadcn components, the site metadata and theme scripts, and the shared
marks and favicons both sites point their `publicDir` at.

## Usage

```css
@import "@missingstudio/ui/tokens.css";
```

```ts
import { entity, links, themeScript } from "@missingstudio/ui"
import { Button } from "@missingstudio/ui/components/button"
```
