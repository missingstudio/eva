# How-to guides

Each guide solves one problem and ends with a way to check that it worked. Except
for [install-eva.md](install-eva.md), they assume Eva is already built. If it is
not, start there or with [tutorial/first-run.md](../tutorial/first-run.md).

| Guide                                          | Use it when                                                                         |
| ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| [install-eva.md](install-eva.md)               | You want a binary on a machine, and to know which build you got.                    |
| [connect-a-provider.md](connect-a-provider.md) | You hold an Anthropic or OpenAI key, or you need a proxy, gateway, or local server. |
| [use-a-subscription.md](use-a-subscription.md) | You pay OpenAI monthly and want that instead of a key.                              |
| [script-with-eva.md](script-with-eva.md)       | You want one answer on stdout, and a non-zero exit when it fails.                   |
| [read-the-trace.md](read-the-trace.md)         | You want what a run did, spent, or failed with, out of the record.                  |
| [theme-a-repository.md](theme-a-repository.md) | You want everyone in a repo to see the same colours and bindings.                   |
